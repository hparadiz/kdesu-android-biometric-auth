# Icon sources

`claude.png` is the 256×256 `claude-desktop` application icon from Anthropic's official
Claude Desktop package (`claude-desktop_1.17180.0_amd64.deb`,
`/usr/share/icons/hicolor/256x256/apps/claude-desktop.png`), retrieved 2026-11-24 from
`https://downloads.claude.ai/claude-desktop/apt/stable/`. Claude is an Anthropic trademark.
It is shown for requests from the Claude CLI and the Claude desktop app; an installed
`claude` or `claude-desktop` theme icon takes precedence in the kdesu dialog.

All other bundled icons are rendered from the installed icon themes (Breeze, Breeze Dark and
their fallbacks) by `make icons`; see `../sources.json`.
